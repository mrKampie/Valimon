Handleiding Valimo Engine v4

Voor het beheren van themes, modes, accents, theme-overrides, componenten, utilities, project packs, oude project-CSS, imports en downloadbare exports.

Aanbevolen standaard: gebruik in nieuwe projecten valimo.css plus alleen de project pack- of projectlaag die werkelijk nodig is.

2. Systeemmodel

Globale systeemlagen

Core bevat foundations, semantische aliases en globale regels.

Themes bevat modes en accents.

Components bevat algemene Valimo-componenten.

Utilities bevat compacte u-*-classes.

Themecontext en projecten

Theme tokens overschrijven tokens binnen één data-valimo-theme.

Theme components voegen componentregels toe binnen dat theme.

Project packs groeperen site- of module-CSS.

Project-CSS bewaart en reviewt oude complete stylesheets.

Database
  → geselecteerd theme
  → core + mode + accent
  → theme token overrides
  → globale + themecomponenten
  → utilities
  → gekoppelde project packs / gereviewde project-CSS

3. Themes gebruiken

Een theme is het centrale record. Het bevat minimaal een naam, slug, mode, accent en status. Daarnaast kan het eigen tokens, componentoverrides en gekoppelde project packs hebben.

Status Gebruik Exportgedrag
draft In ontwikkeling of test. Wordt in v4-final nog in de theme-export vermeld zolang het niet archived is.
active Klaar voor productie. Wordt geëxporteerd.
archived Bewaren, maar niet meer gebruiken. Wordt niet in de theme-recordlijst van de CSS-export opgenomen.

Theme selecteren

Kies een theme in de linker themelijst. De engine laadt daarna de theme tokens, themecomponenten en gekoppelde packs voor dat record.

Theme dupliceren

Dupliceren kopieert de themebasis, theme tokens, themecomponenten en koppelingen naar project packs. De kopie wordt als nieuwe variant gebruikt; controleer daarna altijd naam, slug, status, mode en accent.

Belangrijk: het CSS-record [data-valimo-theme="..."] zet de mode en accent niet automatisch op het DOM-element. Gebruik voorlopig alle drie attributen expliciet: data-theme, data-accent en data-valimo-theme.

4. Tokens

Foundation tokens

Gebruik foundations voor ruwe, systeemwijde waarden: spacing, tekstgroottes, fonts, radius, transitions, control sizes en z-index.

--space-4: 16px;
--radius-1: 2px;
--font-body: 'IBM Plex Sans', sans-serif;
--transition-fast: .2s var(--ease-standard);

Semantische tokens

Gebruik semantische aliases voor functies in plaats van losse kleurwaarden.

--color-page: var(--bg);
--color-panel: var(--surface-1);
--color-control: var(--surface-2);
--color-action-primary: var(--accent);
--color-focus: var(--accent-line);

Theme tokens

Theme tokens gelden alleen wanneer het betreffende data-valimo-theme actief is. Gebruik deze voor kleine afwijkingen van een sterk gedeelde basis.

[data-valimo-theme="portal-blue"] {
  --content-max: 1240px;
  --radius-1: 0px;
  --color-panel: var(--surface-2);
}
Richtlijn: wijzig een foundation wanneer alle projecten mee moeten veranderen. Gebruik een theme token wanneer alleen één theme of projectfamilie afwijkt.

5. Componenten

Globale componenten zijn herbruikbare Valimo-UI-regels, zoals buttons, panels, inputs, nav-items, badges, modals, toasts en tabellen.

.btn {
  display: inline-flex;
  gap: var(--space-2);
  border: 1px solid var(--border);
  border-radius: var(--radius-1);
  background: var(--color-control);
}

Themecomponenten

Een themecomponent wordt in de export gescoped onder het geselecteerde theme. Gebruik deze alleen als een component binnen één theme werkelijk ander gedrag nodig heeft.

[data-valimo-theme="operator"] .toolbar {
  min-height: 42px;
  grid-template-columns: 1fr auto;
}
Vermijd: een themecomponent voor elk klein kleurverschil. Gebruik daarvoor tokens. Componentoverrides zijn bedoeld voor structureel of functioneel verschil.

6. Utility layer

Utilities voeren één kleine taak uit en gebruiken het verplichte u--prefix. Hierdoor botsen ze minder snel met oude projecten.

Categorie Voorbeelden Doel
Spacing u-p-4, u-px-3, u-gap-2, u-m-4 Padding, margin en gap uit de spacingtokens.
Text u-text-sm, u-text-muted, u-text-soft Tekstgrootte of semantische tekstkleur.
Surface u-surface-1, u-surface-2 Neutrale Valimo-oppervlakken.
Border/radius u-border, u-border-strong, u-radius-1 Functionele randen en bijna scherpe hoeken.
Layout u-flex, u-grid, u-stack, u-inline, u-center Kleine composities.
State u-active, u-disabled, u-accent Semantische actieve of uitgeschakelde toestand. 
<div class="u-flex u-items-center u-justify-between u-gap-3 u-p-4 u-surface-2 u-border u-radius-1">
  ...
</div>

Maak geen utility voor een compleet domeincomponent. Een selector als .epg-program-row hoort in een project pack.

7. Project packs

Een project pack is de aanbevolen beheerlaag voor site- of modulefunctionaliteit die niet in de Valimo-core hoort.

Goede packs

  • EPG of videoplayer
  • Voetbalveld en spelerskaarten
  • Dashboardmodule
  • Admin-tabellen
  • Specifieke marketing- of portal-layout

Werkwijze

Maak een pack met herkenbare slug en naam.
Voeg regels toe met een unieke rule key, selector, CSS-block en sort order.
Koppel het pack aan één of meer themes.
Laad de gegenereerde pack-CSS na de algemene Valimo-build.
<link rel="stylesheet" href="valimo.css">
<link rel="stylesheet" href="project-pack-epg.css">
Architectuurregel: een project pack mag de Valimo-core aanvullen, maar moet niet opnieuw fonts, standaardbuttons, algemene inputs of globale surfaces definiëren.

8. Oude Project-CSS en handmatige review

Project-CSS is bedoeld voor complete oude stylesheets die je nog niet hebt opgesplitst. De engine kan het origineel bewaren, vergelijken met de Valimo-basis en een review-export genereren.

Reviewkeuzes

Keuze Effect
Valimo behouden De botsende projectdeclaration wordt niet in de gereviewde projectexport opgenomen.
Project behouden De projectdeclaration blijft als bewuste override staan.
Projectproperty verwijderen De property wordt uit de projectexport verwijderd.

De vergelijking werkt op exacte selector- en propertycombinaties. Een unieke projectproperty blijft staan. 

Valimo:  .btn { padding: 11px 14px; border-radius: var(--radius-1); }
Project: .btn { padding: 20px; border-radius: 20px; min-width: 180px; }

Na keuze “Valimo behouden”:
.btn { min-width: 180px; }
Niet automatisch gedekt: specificiteit, inheritance, shorthand versus longhand, custom properties, runtime classes en selectors die semantisch gelijk zijn maar anders geschreven.

9. CSS importeren

De slimme import analyseert een CSS-block en zet regels eerst in staging. De parser herkent custom properties, theme selectors, utility-achtige selectors, algemene componenten en projectregels.

Importflow

Geef de import een naam en plak CSS.
De engine slaat gevonden custom properties als geïmporteerde foundation tokens op.
Gevonden regels verschijnen in Import staging.
Kies per regel component, utility of project.
Controleer de nieuwe laag en exporteer pas daarna opnieuw.

Classificatie

Detectie Voorbeelden Aanbevolen bestemming
Theme :root, [data-theme], [data-accent] Controleer tokens handmatig; modes en accents worden niet volledig automatisch opgebouwd.
Utility .p-4, .gap-2, .surface-2 Utilitylaag; hernoem bij voorkeur naar u-*.
Component .toolbar, .empty-state, .data-table Globale component als deze voor meerdere projecten geldt.
Project ID-selectors, player, pitch, EPG, timeline, market, admin Project-CSS of een handmatig opgebouwd project pack.
Belangrijk: acceptatie naar “project” maakt in v4-final een legacy Project-CSS-record aan, niet automatisch een project pack. Voor nette nieuwe modules maak je daarna zelf een pack.

10. Exportbestanden

Bestand Inhoud Wanneer gebruiken?
valimo.css Samengestelde algemene build voor het gekozen theme: core, themes, theme tokens, components en utilities. Standaardkeuze voor de meeste projecten.
valimo-core.css Foundations, semantic tokens en globale core-regels. Modulaire build.
valimo-themes.css Modes, accents en administratieve theme selectors. Na core laden.
valimo.tokens.css Themegebonden tokenoverrides van het geselecteerde theme. Na themes laden; direct downloadbaar.
valimo-components.css Globale componenten en, bij theme-download, themecomponentoverrides. Na tokens laden.
valimo-utilities.css u-*-utilities. Na components laden.
valimo-tokens.json Tokens en systeemmetadata voor tooling of JavaScript. Niet als stylesheet laden.
valimo-project-*.css Gereviewde legacy project-CSS. Als laatste laden.
Project pack CSS Beheerde site- of modulelaag. Als laatste laden, na Valimo.

Direct downloaden versus volledige export

Direct downloaden genereert de gekozen inhoud direct uit SQLite. Genereer volledige export schrijft bestanden naar de map van het PHP-script en registreert ze in de exporttabel. De map moet schrijfrechten hebben.

Bekende v4-final inconsistentie: valimo.tokens.css is direct downloadbaar, maar wordt niet door de knop “Genereer volledige export” naar de servermap geschreven. Download deze laag handmatig wanneer je de modulaire bestandsset gebruikt.

11. Wanneer welk CSS-bestand laden?

Optie A — aanbevolen, complete build

<link rel="stylesheet" href="/css/valimo.css">
<link rel="stylesheet" href="/css/project-pack-dashboard.css">

Gebruik dit voor vrijwel alle normale projecten.

Optie B — modulaire build

<link rel="stylesheet" href="/css/valimo-core.css">
<link rel="stylesheet" href="/css/valimo-themes.css">
<link rel="stylesheet" href="/css/valimo.tokens.css">
<link rel="stylesheet" href="/css/valimo-components.css">
<link rel="stylesheet" href="/css/valimo-utilities.css">
<link rel="stylesheet" href="/css/project-pack-dashboard.css">

Gebruik dit wanneer je losse caching, bundling of laagcontrole nodig hebt.

Niet doen: laad niet tegelijk valimo.css én alle losse algemene lagen. Dan laad je dezelfde regels dubbel.

12. Een oud project migreren

Maak een back-up van de oude stylesheet en HTML.
Kies een Valimo-theme en laad eerst alleen valimo.css.
Upload de oude CSS als Project-CSS en open Vergelijken.
Laat Valimo winnen bij globale buttons, inputs, typography, surfaces, borders en radius.
Behoud projectspecifieke functionaliteit zoals grids, player, EPG, veld, specifieke IDs en JS-hooks.
Splits stabiele modules uit naar project packs.
Vervang kleine layoutregels door u-*-utilities waar dat de HTML duidelijker maakt.
Test states en responsive gedrag en download daarna de review-export.

Praktisch migratievoorbeeld

Oude CSS:
.btn { border-radius:18px; background:#334; padding:16px 24px; }
.epg-row { display:grid; grid-template-columns:160px 1fr; min-height:60px; }

Beslissing:
.btn      → Valimo behouden
.epg-row  → behouden en later naar project pack “epg” verplaatsen

13. Waar hoort een regel?

Vraag Ja
Is dit een ruwe waarde die overal geldt? Foundation token
Beschrijft het een functionele rol? Semantic token
Verandert het neutrale canvas tussen dark en light? Mode
Is het de betekenisvolle signaalkleur? Accent
Wijkt slechts één theme af? Theme token of themecomponent
Is het een herbruikbaar UI-element voor meerdere sites? Component
Doet het precies één kleine layout- of stijlfunctie? u-* utility
Is het een beheerde site- of modulefunctie? Project pack
Is het nog een grote oude stylesheet? Project-CSS + review

14. Feitelijke beperkingen van v4-final

  • data-valimo-theme activeert niet automatisch de gekoppelde mode en accent.
  • De parser is geen volledige browserwaardige CSS-parser.
  • Import van theme blocks maakt modes en accents niet automatisch volledig aan.
  • Import naar project maakt legacy Project-CSS, niet automatisch een project pack.
  • De CSS-review vergelijkt exacte selectors en properties; indirecte cascadeconflicten blijven handwerk.
  • valimo.tokens.css ontbreekt in de serverbrede volledige export, maar is wel direct downloadbaar.
  • Project pack-download en documentatie kunnen afhankelijk zijn van hoe je de gegenereerde pack-output uit de admin haalt; controleer de exportpagina na het koppelen.
  • Wijzigingen aan gedownloade bestanden lopen niet automatisch mee: opnieuw downloaden of exporteren is nodig.

15. Checklists

Nieuw project

  • Theme gekozen of aangemaakt
  • Mode en accent gecontroleerd
  • data-theme, data-accent en data-valimo-theme ingesteld
  • valimo.css geladen
  • Alleen noodzakelijke project pack(s) erna geladen
  • Dark/light en focus getest
  • Geen oude globale CSS onder Valimo geladen

Na een systeemwijziging

  • Preview gecontroleerd
  • Themeoverrides gecontroleerd
  • CSS opnieuw gedownload/geëxporteerd
  • Project packs opnieuw getest
  • JSON opnieuw gedownload wanneer tooling dit gebruikt

Voor productie

  • Theme status active
  • Geen onbedoelde draftvariant in gebruik
  • Project-CSS-review afgerond
  • Geen dubbele algemene build geladen
  • Responsive, hover, focus, disabled en modal/toast getest

16. Migratie met Valimo Migration Analyzer

Gebruik de Valimo Migration Analyzer om bestaande HTML-, PHP-, CSS- en JavaScriptprojecten te analyseren voordat je ze omzet naar Valimo. De analyzer inventariseert classes, selectors, JavaScript-afhankelijkheden en mogelijke migraties.

  • Maak een nieuw analyseproject aan.
  • Upload HTML-, PHP-, CSS- en JavaScriptbestanden.
  • Upload daarnaast de actuele valimo.css als referentie.
  • Controleer Class Analysis, CSS Conflicts en het migratierapport.
  • Maak aliasregels zoals tab-btn → btn.
  • Kies per class: Replace, Compatibility, Project Pack, Review of Ignore.
  • Genereer een Compatibility PHP-bestand voor bestaande projecten.
  • Pas daarna pas de echte HTML en CSS aan.
Legacy class
      ↓
Alias register
      ↓
Canonical Valimo class
      ↓
Compatibility PHP + Review export
      ↓
Definitieve migratie
Aanbevolen werkwijze: gebruik de compatibilitylaag tijdelijk zodat oude projecten blijven werken, vervang daarna stap voor stap de legacy classes in HTML en verwijder de aliases pas wanneer ze nergens meer worden gebruikt.
